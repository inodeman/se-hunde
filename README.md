# Se hunde

Documental animado de **10:00** en español. La Ciudad de México no se cae de un día para otro: se arruga. Un satélite (NISAR, NASA e ISRO) acaba de medir el movimiento, el dato de 50 cm al año no significa lo que circula en redes, y el lago de Texcoco empezó a asomarse otra vez en enero de 2026.

Canal dentro del reproductor: **VASO**.

## Verlo

```bash
npm install
npm run dev
```

## Por qué este tema

En octubre de 2026 el hundimiento del Valle de México volvió a los titulares: lecturas de radar desde órbita, el déficit de acuíferos y la apertura del Parque Ecológico Lago de Texcoco. Es visual, se puede contar en diez minutos y corrige un número que ya es viral.
